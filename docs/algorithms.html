Click the landscape to choose a starting point, or use the sliders. Each method uses the same Armijo backtracking rule.

Gradient descent uses the negative gradient. Damped Newton shifts the Hessian if it is indefinite or nearly singular. BFGS estimates an inverse Hessian from successive steps and resets its estimate if the curvature check fails.

The plot uses a floor of 10⁻¹² for zero or smaller objective values. Gradient norm is evaluated separately and the convergence tolerance is 10⁻⁶. Function call counts include the initial objective evaluation and line-search trials.
